# RAID Schedule Team 13

Консольная программа на Go, которая отображает RAID-расписание в виде таблицы.

## Команда

- Сабира — `main.go`, объединение программы
- Анар — `validate.go`, проверка входных данных
- Камила — `render.go`, отрисовка таблицы и цветных ячеек

## Возможности

Программа:

- Выводит расписание в таблице с рамками
- Показывает пустые ячейки
- Показывает занятые слоты как `###`
- Показывает важные события как `!!!`
- Проверяет, что расписание не пустое
- Проверяет одинаковую длину всех строк
- Разрешает только символы `0`, `1` и `2`

## Значения в расписании

| Символ | Значение | Отображение |
|---|---|---|
| `0` | Пустой слот | Пустая ячейка |
| `1` | Занятый слот | `###` |
| `2` | Важное событие | `!!!` |

## Запуск программы

Откройте терминал в папке проекта и выполните:

```bash
go run .
```

## Пример результата

```text
+---------+---------+---------+---------+
|         |   ###   |         |   !!!   |
+---------+---------+---------+---------+
|   ###   |   ###   |         |         |
+---------+---------+---------+---------+
|         |         |   ###   |         |
+---------+---------+---------+---------+
|   !!!   |         |         |   ###   |
+---------+---------+---------+---------+
```
