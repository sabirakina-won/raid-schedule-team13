# Проект: Цветное ASCII-расписание

Проект печатает расписание в виде цветной ASCII-таблицы.

## Запуск

```bash
go run .
```

## Правила

- `1` (занят) → красный
- `2` (важно) → желтый
- `0` (свободно) → без цвета

## Пример

### Ввод (внутри `main.go`)

```go
printSchedule([]string{"0102", "1100", "0010", "2001"}, "###", "!!!")
```

### Вывод

> Макет — во время выполнения `###` отображаются красным цветом, а `!!!` — жёлтым.

```text
+---------+---------+---------+---------+
|         |   ###   |         |   !!!   |
+---------+---------+---------+---------+
|   ###   |   ###   |         |         |
+---------+---------+---------+---------+
|         |         |   ###   |         |
+---------+---------+---------+---------+
|   !!!   |         |         |   ###   |
+---------+---------+---------+---------+
```

## Пример 2

### Расписание 3×5 с различными символами

```go
printSchedule([]string{"01020", "11002", "00210"}, "*", "$")
```

### Вывод

```text
+---------+---------+---------+---------+---------+
|         |    *    |         |    $    |         |
+---------+---------+---------+---------+---------+
|    *    |    *    |         |         |    $    |
+---------+---------+---------+---------+---------+
|         |         |    $    |    *    |         |
+---------+---------+---------+---------+---------+
```
