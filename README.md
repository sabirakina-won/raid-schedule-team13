Это проект, который печатает расписание в виде цветной таблицы ASCII.

Как его запустить: go run .

Правила:
1(занят) → красный
2(важно) → желтый
0(бесплатно) → без цвета

Пример: 
Ввод (внутри main.go):

printSchedule([]string{"0102", "1100", "0010", "2001"}, "###", "!!!")
Вывод (макет — во время выполнения ###ячейки красные, а !!!ячейки желтые):

+---------+---------+---------+---------+
|         |   ###   |         |   !!!   |
+---------+---------+---------+---------+
|   ###   |   ###   |         |         |
+---------+---------+---------+---------+
|         |         |   ###   |         |
+---------+---------+---------+---------+
|   !!!   |         |         |   ###   |
+---------+---------+---------+---------+
Расписание 3х5 с различными символами:

printSchedule([]string{"01020", "11002", "00210"}, "*", "$")
+---------+---------+---------+---------+---------+
|         |    *    |         |    $    |         |
+---------+---------+---------+---------+---------+
|    *    |    *    |         |         |    $    |
+---------+---------+---------+---------+---------+
|         |         |    $    |    *    |         |
+---------+---------+---------+---------+---------+
